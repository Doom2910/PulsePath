# PulsePath 🚑

PulsePath is an AI-powered emergency navigation system designed to help ambulance drivers reach hospitals faster.

## Features

- AI voice assistant
- Smart route optimization
- Green corridor simulation
- Live ambulance tracking
- Traffic signal prediction
- Hospital ETA updates
